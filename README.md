# 携程酒店订阅 · The Art of Staying

一页酒店体验画册，以法国圣特罗佩为度假背景。使用真实摄影，首屏提供 360° 大厅交互，包含按晚预订演示和酒店行程助手示例。全部交互留在当前页面。

## 本地预览

需要 Node.js 18 或更新版本，不需要安装运行依赖。

```sh
npm start
```

打开 `http://127.0.0.1:4173`。也可以使用任意静态文件服务器发布本目录。

## 内容与交互

- 360° 大厅首屏：真实球面全景照片，鼠标靠近画面边缘即可平滑环顾，中央区域静止；停在导航、按钮或介绍卡片上时停止跟随。保留拖拽、滚轮缩放。进入页面缓慢自动环视，首次操作后停止；仅点击“自动环视”才重新开启。
- 场景热点与底部导览分别指向真实照片中的雕花楼梯、古典拱廊、雕饰顶面和休息区。点击后平滑转向相应视角并展示介绍，支持键盘操作与 Escape 关闭，全程留在当前页。
- 手机支持触摸拖动、双指缩放和主动开启的体感环视。体感依赖安全连接与设备传感器；需要授权的浏览器仅在用户点击后申请权限，拒绝、异常或无传感器数据时继续使用触摸操作。体感相对当前视角校准，手动操作、离开首屏或切到后台时关闭。
- 方向键、＋/− 和 Home 支持键盘操作。点击首屏按钮或“慢慢往下”继续浏览。
- 电脑首屏使用白色小帆船鼠标图案，支持在全景、导航、热点和两个入口按钮上直接操作；触摸屏保持原生触摸体验。
- 尊重减少动态效果偏好；全景在屏幕外或页面后台时暂停自动环视。无法显示全景时保留同一实拍的静态视角与页面导航。
- 餐厅暮色、海鲜、牛排、香槟、泳池和 SPA。
- 三段独立房型大图，可切换照片与打开图库。
- 海景房 ¥3,280 / 晚；自然原木房 ¥2,280 / 晚；亲子儿童房 ¥3,880 / 晚，均为人民币示例价。
- 预订演示：房型、入住/离店日期、成人/儿童人数、晚数与总价、完成演示。日期按法国当地日期校验，按日历日期计算晚数，跨夏令时不影响晚数。
- 酒店助手：机场到店方式对比、目的地路线、建议出发时间与模拟倒计时、航班延误事件。
- 手机界面内循环播放到店提醒的使用演示：模拟手指点击、路线描绘、屏幕内滚动、加入提醒与时间线反馈。可暂停、重播；用户操作立即接管，屏幕外、后台或弹窗打开时停止。减少动态效果偏好下不自动播放。
- 页尾为独立的 360° 海滨实景：鼠标按住拖动环顾上下左右，滚轮缩放，手机单指环顾、双指缩放。支持加减按钮、方向键和 Home 复位；“纯享海景”可收起标题，随时恢复预订入口。靠近这一段才加载全景，电脑使用 8K、手机使用 4K；全景不可用时展示同一照片的静态视角。
- 可加入/移除页面内示例行程；刷新后重置，不推送系统通知。
- 适配电脑、平板和手机，支持键盘操作、弹窗关闭和减少动态效果偏好。

本项目是产品体验演示，不代表真实酒店库存、报价或有效订单。摄影来自不同酒店和餐饮场景，不将这些设施组合描述为同一家真实酒店的实际配置。地图为路线示意，交通费用和行程时间为演示数据。

首屏现使用 The Biltmore Los Angeles 历史大堂 Rendezvous Court 的真实 360° 摄影，作为文艺复兴宫殿风格的酒店体验参考。其金色雕饰、石材拱廊、古典吊灯与双侧楼梯均来自实景；具体布局与色彩以实拍为准，未生成或补入接待前台、旋转楼梯等不存在于照片中的设施。素材地点位于洛杉矶，不标称它属于圣特罗佩酒店。此前的 Poly Haven 全景与 Le Negresco 广角实拍保留在素材目录。

## GitHub Pages

本项目无需构建。所有资源使用相对路径，支持 GitHub Pages 的项目子目录地址。

1. 将源码上传到公开 GitHub 仓库，例如 `ctrip-hotel-subscription`。
2. 在仓库的 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)`，保存。
4. GitHub 完成发布后，页面位于 `https://<用户名>.github.io/<仓库名>/`。

根目录包含 `.nojekyll`，无需服务器、数据库、密钥或外部 API。照片保存在 `assets/photos/`，页面浏览不会依赖第三方图片服务器。

## 修改内容

- `index.html`：页面内容、结构、房型显示价格。
- `styles.css`：色彩、字体、版式与手机适配。
- `app.js`：房型数据、图库、预订计算、助手示例。
- `assistant-demo.js` 与 `assistant-demo.css`：手机内使用演示与播放控制。
- `panorama.js` 与 `panorama.css`：首屏全景交互与控制栏样式。
- `beach-panorama.js` 与 `beach-panorama.css`：页尾海滩全景与控制栏。
- `assets/vendor/pannellum/`：固定版本 Pannellum 2.5.6 与 MIT 许可，页面运行不请求外部 CDN。
- `assets/photos/`：优化后的真实照片。`palace-lobby-*` 是当前首屏，原始六面摄影仅转换成球面/普通透视投影并压缩。
- `assets/sailboat-cursor.svg` 与 `.png`：手绘白色小帆船鼠标图案及浏览器使用的透明 PNG；旧海鸥图案留在素材目录。
- `assets/sources.json` 与 `ASSETS.md`：照片来源与第三方素材说明。
- `scripts/serve.mjs`：本地预览服务。
- `scripts/verify.mjs`：交互与手机布局检查，需要本机可用的 Playwright 与 Chromium/Chrome。
- `scripts/verify-assistant-demo.mjs`：手机使用演示、暂停重播、手动接管及减少动态效果检查。
- `scripts/verify-panorama.mjs`：全景旋转、自动环视停止、缩放、触摸、降级和子目录检查。
- `scripts/verify-beach-panorama.mjs`：页尾海滩全景的鼠标、键盘、触摸缩放、观景入口、预订与降级检查。

修改价格时同步更新 `index.html` 与 `app.js`，避免展示价和计算价不一致。

## 验证

```sh
npm run check
```

浏览器检查脚本可通过 `HOTEL_PLAYWRIGHT_PATH` 指定已安装的 Playwright 模块，通过 `HOTEL_CHROME_PATH` 指定浏览器可执行文件。先启动预览服务，再运行：

```sh
node scripts/verify.mjs
```
